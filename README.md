# Recflow

Record the screen. Not a studio.

Recflow is a floating desktop dock. Record a region, a display, or a window, then stop. The video is already in the folder you chose. There is no account, and nothing is uploaded.

## Download

Installers are on the [latest release](https://github.com/Kether-Labs/recflow/releases/latest).

| System | File | Video |
| --- | --- | --- |
| Linux | `.deb` (`.rpm`) | WebM |
| Windows 10 and 11 | `.exe` installer | MP4 |

macOS is not available.

## Install

**Linux.** Download the `.deb` from the latest release, then:

```bash
sudo apt install ./recflow_*_amd64.deb
